# refugio-tina2

Refugio de animales

En este proyecto hice un programa que simula un día en un refugio con Luna, Rocky y Kiwi. Los animales se presentan usando cowsay, realizan actividades como comer, jugar y dormir, y al final se muestra la energía que le quedó a cada uno.

Requisitos:

Para ejecutar el proyecto se necesito tener instalado:
- Python 3-para correr el programa.
- pip-para instalar las dependencias.
- Git- para descargar el repositorio.

Instalación
1. Descargar el proyecto
Abrir la terminal y escribe este comando para clonar el repositorio:
powershell
git clone https://github.com/Tinamoreno04/refugio-tina2.git

2. Entrar a la carpeta
Después de descargarlo, entra a la carpeta del proyecto:
powershell
cd refugio-tina2

3. Instalar las dependencias
El programa usa cowsay para las presentaciones de los animales. Para instalar la versión indicada en `requirements.txt`, ejecutar:
powershell
python -m pip install -r requirements.txt

Ejecución
cuando termina la instalación, escribi este comando desde la carpeta del proyecto:

powershell
python main.py


aqui se ve la presentación de cada animal y, al final, la energía que le quedó después de sus actividades.
